Case Studies
============

Use Petrophys to answer complete interpretation questions rather than examine
one method at a time. Each case study states its deliverable, works through the
available evidence, and keeps limitations and study assumptions visible.

The studies use public data and saved outputs, so every page can be read in the
browser without access to a proprietary project database.
