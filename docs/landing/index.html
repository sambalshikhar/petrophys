Quickstart

Start with a bundled well.

import petrophys as pp

well = pp.read(pp.sample("30_6-5"))
result = pp.interpret(well, rw=0.07, rw_meas_temp_f=230)

result.print_trace()                     # what ran, what didn't, and why
pp.plot(result, top=2800, bottom=3000).show()
result.to_las("interpreted.las")
