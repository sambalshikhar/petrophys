# Case Studies

These notebooks apply multiple Petrophys modules to realistic interpretation
questions using the bundled Geolink and Costa datasets.

| Notebook | Scope |
|----------|-------|
| [`cs1_full_formation_evaluation_30_6-5.ipynb`](cs1_full_formation_evaluation_30_6-5.ipynb) | Full clastic formation evaluation and completion screening |
| [`cs2_carbonate_rock_typing_costa.ipynb`](cs2_carbonate_rock_typing_costa.ipynb) | Carbonate characterization, core calibration, and rock typing |
| [`cs3_field_screening_costa_17wells.ipynb`](cs3_field_screening_costa_17wells.ipynb) | Field-scale screening and well ranking |
| [`cs4_imperfect_well_recovery_16_7-1.ipynb`](cs4_imperfect_well_recovery_16_7-1.ipynb) | Interpretation of an incomplete log suite with uncertainty flags |
| [`cs5_saturation_model_sensitivity_30_6-5.ipynb`](cs5_saturation_model_sensitivity_30_6-5.ipynb) | Saturation-model selection and parameter sensitivity |

The case studies build on the notebooks in
[`part_a_foundations`](../part_a_foundations/) and
[`part_b_advanced`](../part_b_advanced/).
