# GeoLink samples

Data attribution: GEOLINK-S2. The public
[GeoLink distribution by Lukas Mosser](https://github.com/LukasMosser/geolink_dataset)
lists CC BY-SA 4.0 for data and analysis. Petrophys uses curated LAS files,
including interpreted and core-related additions.

Additional information comes from Norwegian Offshore Directorate
[FactPages data and reports](https://factpages.sodir.no/en), as identified by
the maintainer. Contains data under NLOD distributed by the Norwegian Offshore
Directorate; Petrophys selects, combines and derives information from it.
Report-originator and asset-specific rights remain relevant to report-derived
content, as stated in FactPages' use-of-content notice.
